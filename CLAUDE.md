## Collaboration mode

This is a learning project (école 42). Per `.ai/roadmap.md` §2, the intended
mode is mentor/pairing, not autopilot: one phase and one step at a time,
signatures agreed before implementation, and the "why" explained before the
"how" — the defense (soutenance) is graded on understanding, not just
working code. Session context lives in `.ai/decisions.md` (append-only
decision log), `.ai/next-steps.md`, `.ai/state.md`, and `.ai/roadmap.md`.
Check current status there before assuming what's implemented.
